How to Diagnose a Keyboard That's Not Working

Four steps to pinpoint exactly which keys are broken — takes under two minutes.

01
Click on This Page
Click anywhere in the diagnostic area above. This tells your browser to listen for key events from your keyboard rather than from any other open window or app.
02
Press Every Key
Go row by row across your keyboard. Every key that works will turn green. Take note of any key that stays dark after pressing — those are your problem keys.
03
Use "Show Broken"
Click the "Show Broken" button to highlight all keys you haven't successfully tested yet. This makes it easy to confirm which keys are genuinely unresponsive.
04
Follow the Fix Guide
Once you know which keys fail, scroll to the Fix Guide below for step-by-step troubleshooting based on your specific problem pattern.

Keyboard Not Working — Fix Guide

Match your diagnostic result to the right fix. Start with the quickest steps first.

All keys dark
Keyboard not responding at all
Try a different USB port. Replace wireless batteries or re-pair Bluetooth. Check Device Manager for driver errors. Test on a different computer to isolate keyboard vs computer.
One or two keys
Specific keys not working
Remove the keycap and clean with compressed air. Check for debris or liquid residue. On mechanical boards, try replacing the individual switch. On membranes, inspect the rubber dome under the keycap.
Whole row dark
Entire row unresponsive
A full row failure usually points to a damaged PCB trace or matrix line. On laptops this can follow a liquid spill. Try updating or reinstalling keyboard drivers — sometimes a firmware reset helps.
Random keys dark
Scattered keys failing
Check if Num Lock, Fn Lock, or Game Mode is accidentally active — these can remap or disable groups of keys. Try holding Fn + Esc or Fn + F11 to toggle keyboard modes. Check your OS keyboard layout settings.
Keys type wrong char
Keys register but output wrong
The key is working but your OS language or layout setting is wrong. Go to Settings → Time & Language → Language and verify the correct keyboard layout is selected. Also check if Caps Lock or Num Lock is on.
Keys stick on screen
Keys stay gold (stuck pressed)
A key that stays lit gold after release has a physically stuck switch or keycap. Remove the keycap and check if the switch returns freely. Clean with isopropyl alcohol. On laptops check for debris under the scissor mechanism.

Keyboard Not Working — FAQ

Answers to the most common keyboard troubleshooting questions.

The quickest way is to test the keyboard on a second computer. If the same keys fail on a different machine, it's a hardware problem. If all keys work on the second machine, the issue is software — driver, OS setting, or application — on your original computer.

This diagnostic tool helps you establish the pattern. All keys failing simultaneously points to connection or driver. Specific scattered keys failing points to physical hardware damage.

Windows updates occasionally reset accessibility settings, change keyboard layout assignments, or update HID drivers in ways that affect keyboard behaviour. Try these steps in order:

  1. Open Settings → Accessibility → Keyboard and turn off Filter Keys, Sticky Keys, and Toggle Keys.
  2. Open Device Manager, find your keyboard under "Keyboards", right-click and choose "Update driver".
  3. If that fails, right-click → Uninstall device, then unplug and replug the keyboard to reinstall the driver from scratch.
  4. Check Settings → Time & Language → Language and verify your keyboard input method hasn't changed.

Laptop keyboards are generally more repairable than people assume. If only specific keys fail, cleaning under the keycap (most laptop keycaps can be gently removed with a flat tool) resolves it in many cases. Scissor-switch and butterfly mechanisms are delicate but can be cleaned with compressed air.

If the entire keyboard fails, check if the ribbon cable connecting the keyboard to the motherboard has worked loose — a common issue on laptops that have been dropped. This is usually accessible after removing the bottom panel. If the keyboard is completely unresponsive and a USB external keyboard works fine, the internal keyboard likely needs replacement.

Act quickly. Unplug the keyboard immediately and do not press any keys. Turn it upside down and gently shake out any liquid. For a desktop keyboard, leave it upside down in a warm room for at least 48 hours. Do not use a hairdryer — heat can warp keycaps and damage PCB components.

After drying, use this diagnostic to identify which keys were affected. Sticky keys after a sugary drink spill can often be fixed by removing keycaps and cleaning with distilled water or isopropyl alcohol on a cotton swab. Corrosion from water may require PCB cleaning with isopropyl and a toothbrush.

It depends on which number keys. If the top-row number keys (above QWERTY) don't work, Num Lock is not the cause — those are standard keys and should always register. Try disabling Fn Lock or checking if a game mode is active.

If the numpad numbers aren't working, Num Lock is almost certainly the cause. Press the Num Lock key once and try again. On laptops without a dedicated numpad, Num Lock may also affect the embedded numpad that shares keys with letters like J, K, L, U, I, O — turning Num Lock off will restore normal letter output for these keys.

Completely safe. This diagnostic runs entirely in your browser using the JavaScript KeyboardEvent API. No keystroke data is ever transmitted to any server, stored, or logged. You can verify this yourself by opening your browser's developer tools and checking the Network tab — you will see zero requests made when you press keys.
